Read the canonical [changelog](/r2x-core/release-notes/) and [GitHub releases](https://github.com/NatLabRockies/r2x-core/releases).
The changelog page is generated directly from the repository root `CHANGELOG.md`.
The [PyPI package page](https://pypi.org/project/r2x-core/) lists published distributions and Python requirements.

These pages describe `main`.
For an installed release, select its tag in [the repository tag browser](https://github.com/NatLabRockies/r2x-core/tags) and open its documentation directory.
Tagged source documentation is available through GitHub; separately hosted historical builds are not advertised.
