# Results

For complete API documentation of result types, see [api](/r2x-core/references/api/).

## Quick Reference

- [`Result`](https://pypi.org/project/rust-ok/) - Result container from rust-ok
- [`Ok`](https://pypi.org/project/rust-ok/) - Successful result value from rust-ok
- [`Err`](https://pypi.org/project/rust-ok/) - Error result value from rust-ok
- {py:func}`~r2x_core.is_ok` - Check for Ok results
- {py:func}`~r2x_core.is_err` - Check for Err results
